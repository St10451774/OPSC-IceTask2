# OPSC ICE Tasks 1 & 2

This repository contains an Android Studio Kotlin project scaffold satisfying the ICE Activity 1 and ICE Activity 2 requirements:

- Two fragments with navigation and a Retrofit-based web service (Fragment 1 = Home, Fragment 2 = PostFragment)
- Two additional fragments for adding and viewing records stored in a SQLite database (Fragment 3 = AddDataFragment, Fragment 4 = ViewDataFragment)

Package: com.example.iceapp

See app/ for the Android module. Enable ViewBinding (already configured in app/build.gradle).
